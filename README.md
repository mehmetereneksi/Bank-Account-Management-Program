# Bank Account Management Program

This project is a bank account simulation developed to practice and understand Object-Oriented Programming (OOP) concepts in JavaScript.

## 🚀 Features & Implementation
- Created a `BankAccount` object using the `class` structure.
- Defined `deposit` and `withdraw` methods to manage the balance.
- Stored transaction histories as objects within an array.
- Filtered and formatted the transaction history using modern JavaScript array methods (`filter`, `map`, `join`).

## 🛠️ How to Run
This project does not have a graphical user interface (UI). The code logic runs directly in the browser console.

1. Open the `index.html` file in your browser (or click the live GitHub Pages link).
2. You will see a blank white page. Press **F12** on your keyboard (or right-click and select "Inspect").
3. Switch to the **Console** tab.
4. You can view the account balance and transaction logs in this area.
